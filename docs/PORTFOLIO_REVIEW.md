# Prepare to discuss this portfolio

Before sharing this repository with an admissions committee, review the code and be able to explain the following in your own words:

- How a FASTA parser detects duplicate IDs and invalid protein symbols
- Why an alignment needs equal sequence lengths before site-level QC
- What occupancy, variable sites, and parsimony-informative sites mean
- The difference between a full alignment and a trimmed alignment
- What MAFFT, ClipKIT, and IQ-TREE each contribute
- Why the model and bootstrap settings must be documented
- What the run manifest and SHA-256 hashes do and do not prove
- Why a supported clade or nearest tree tip is not sufficient proof of orthology
- Which parts you personally designed, adapted, reviewed, and tested

Do not claim the full biological analysis completed unless you have inspected the actual logs and reports from a successful run.
